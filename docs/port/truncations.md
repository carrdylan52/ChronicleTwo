# Pointer truncations

Generated by `tools/kazarov/scripts/port_truncations.py` from the port's compile commands; do not edit by hand.
Every cast of a pointer to an integer narrower than a pointer in `ps2/src`, `port/src` and their
headers. `darkchronicle` is PIE and its arenas are ordinary mappings, all above 4 GiB as on arm64
macOS (whose low 4 GiB are its hard page zero), so a **round-trip** site that runs faults at
once; each one is widened in `port/src`. `--check` (CI) fails while one is listed or while this
file is stale.

- **round-trip**: the value comes back as a pointer (cast back, stored or passed into an int that is
  cast back somewhere, returned from a function whose result is cast back, or an absolute address
  added to a pointer as an offset).
- **low-bits**: only the low bits are used (masks, modulo, shifts, differences of two truncated
  pointers, tests, comparisons, a pointer field holding a file offset added to a base).
- **escapes**: stored into memory, an aggregate or an unknown callee, and never seen cast back.
- **resolved**: a round trip whose value only becomes a pointer again in a replaced or dead function
  (the replacement recovers the pointer).

State of the enclosing function in the linked `darkchronicle`: **port** (port/src's own code),
**replaced** (a ps2/src body a `PORT_OVERRIDE` definition in port/src replaces; never compiled),
**retail** (a ps2/src body that is linked and can run), **dead** (dropped by `--gc-sections`; never
runs).

Origin is where the pointer points, where the expression shows it: **image** (a global, a literal,
a function), **stack**, **arena** (an arena allocation or global), **parameter**, **field**,
**global pointer**, **local pointer**, **call**, **this**.
