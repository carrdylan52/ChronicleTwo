## ColCheck fish lifetime

Testing the actual `fish[no]` slot for null before assigning the selected
fish to `me` resolves the previous exchange of `s2` and `s3`. MWCC eliminates
the redundant slot load and keeps the selected fish in retail's `s3`.
The two source accesses therefore produce one machine load at function
offset `+0x44`. This is a real null check followed by a binding, without
an added object, artificial dependency, or compiler-profile override.

The draft improves from 60/448 differing words to **0/448**. Its native
symbol size is `0x6F8`, agreeing with retail's 1,784-byte symbol; the manifest
extent includes eight zero padding bytes. A private activation compiled
through `mwccgap.sh` and `fixup_sections.sh` passes the complete unit:
`0x11C34` allocated bytes and 3,248 resolved relocations.

**The function remains guarded.** Its inherited obstacle loop still advances
`point++` over an array. That source violates this lane's pointer-induction
rule even though its instructions match. An indexed replacement must also
match before promotion. The retained change improves the fish binding only.
