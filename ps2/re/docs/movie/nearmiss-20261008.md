## Result

The canonical draft remains **9/200** words with a `0x320` body.
Offsets `+0x78`, `+0x90`, `+0x94`, `+0x98`, `+0xCC`, `+0xD4`, `+0xDC`,
`+0xF4` and `+0x108` exchange the wrap path's ring count and address mask
between `a2` and `a3`. No guard, source, header or profile row is changed.

## New exclusions

All measurements use the canonical Satan's Fiddle adapter and flags in
`chronicletwo_dev:sf-d8bf13c`, preserving the existing local optimization
level 4 around the restart function.

- Retail-local restart and channel-control functions are tested with static
  declarations and definitions in private source/header copies. Restart
  alone, either channel helper alone, and the three together retain nine.
- Moving each real local's declaration first or last gives a nine-word
  best result. Moving madr, qwc or fifo_bits changes saved-register choices
  elsewhere; reversing or grouping declarations gives 15–26 words.
- Unsigned FIFO bits, FIFO quadword count or current FIFO index retain nine.
  An unsigned following FIFO index gives 25. Initializing the saved IPU/DMA
  values at their first assignments gives 9–24 words; initializing all five
  saved values together retains nine.
- Unsigned and inverted forms of the real 28-bit mask retain nine.
  New legal orderings of the first wrap calculations give 9–12 words.
  Reversing qwc and extent preparation retains nine; no ordering removes
  the count/mask permutation.
- Using `&buf->tag[index]` and the existing `data_bytes` array view for
  endpoints also retains nine. This private form removes the inherited
  pointer-add/subtract expressions without improving its word score, so
  it is not substituted for the retained source checkpoint.

The full wrapper/fixup probe checks `0x3978` bytes and 539 relocations and
has one canonical problem: restart bytes at `0x0029E1AA`. The other native
functions and resolved relocations are preserved.

objects pass, with only nd_meswin/DrawMesWin and actscript/_SHOT failing.
PAL differs by exactly 0x26 text bytes, first at 0x0015C5AD; all other
file-backed sections pass and memory ends at 0x01F64A00. Regenerating
`ctx`, `objdiff` and `progress/report.json` confirms 6,745 matched functions,
115 guarded drafts, ten assembly-only functions and two fuzzy functions.
All 148 objects outside gyorace retain their baseline file hashes; the
changed gyorace object passes its complete allocated-byte and resolved-
relocation check. No function is promoted in this wave.
