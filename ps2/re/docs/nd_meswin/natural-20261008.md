# nd_meswin natural access (2026-10-08 night)

Byte-identical object (`check_objects nd_meswin`: 0xBF28 bytes, 1364 relocations).

## Replaced
- `ClsMes::GetTextLineDataTop`, `GetTextLineDataTop_system`: the message file's line index (after
  the leading count, pairs of `u16` line id and text offset relative to `entries + count`) is read
  as `(u16) entries[i * 2 + 1]` / `(u16) entries[i * 2 + 2]` in a plain `for` loop, replacing the
  `off += 4` byte walk and the `(i << 2) + (int) entries + 4` address.
- Both `MakeMesWinTbl_value` overloads: redundant `(char *)` casts on `char text[]`.

## Kept
- `signed char *` views of message text in the escape and `@` scanners: character-signedness
  conversions of the same text, not reinterpretations of other data.
