# dataread: natural typed access (2026-10-08)

## Replaced

- `DivPathName`: the directory copy walks `char *out` and `char *in`, and
  the separator search reads `path[last]`, instead of `(s8 *)` views of the
  `char *` parameters.
- `LoadFileBG`, `LoadFileCacheBG` and `GetPackFile` (by name) test for an
  empty name with `*name` / `*path` instead of `*(s8 *)` views.
- `InitCDFile`: the search result is a `sceCdlFILE file` passed as `&file`, with the start
  sector read as `file.lsn`, instead of an `int file[9]` cast to `sceCdlFILE *`. The SDK
  structure is 36 bytes: `sceCdlFILE` gains its final `u_int flag` (libcdvd.h), which the
  32-byte declaration lacked; movie's `StrFile` drops the `unk_20` it had in that place.
- `InitCDFile`: the name walk uses `char *name` without the `(s8 *)` view.
- `GetDevType`: the device separator test reads `path[1]` instead of `*(s8 *) (path + 1)`;
  `char` loads with `lb` either way.

## Kept

- `GetPackFile` (by name and by index): pack entries are walked by their
  serialized `next` byte offsets and the file data is found at the entry's
  `offset`, so the `(u8 *) entry + ...` steps follow the file format.
