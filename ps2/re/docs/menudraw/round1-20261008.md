# Round-1 drawing reconstruction at b1220c8

The fresh October 8 baseline has 195 matching functions and three guarded
native drafts in menudraw. The complete build object matches 0x14058 allocated
bytes and 2,584 relocations. Native comparisons use the canonical SF adapter,
existing menudraw profile and relocation-masked words. No assembly is written
or modified, and no profile or header change is retained.

## MenuFormDrawNormal

Fresh decompile.sh output agrees with the documented part, texture-info,
rectangle, effect and colour types. GetNowPosRGBA returns zero when the part
or its effects are unavailable, and one when effects are applied. The signed
shadow offset, unsigned vibration bytes and signed vibration counts retain
their existing declarations. The colour loop and integer rectangle copies
remain semantically unchanged.

The inherited PlusF, FormPart and PartTex wrappers are removed. Parts use
`&parts[i]`, textures use `part->tex`, and the horizontal shadow offset is a
real float local assigned from the signed byte before adding it to the
position. All four gradient pointers have function scope, while part,
texture-info and texture pointers have iteration scope. Their declaration
order changes compiler allocation without introducing storage, helpers or
new game behavior.
