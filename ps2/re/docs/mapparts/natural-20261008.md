# mapparts: natural typed access (2026-10-08)

## Replaced

- `CMapParts::DrawSub`: the piece carried by each list node is `&node->data`
  instead of `(CMapPiece *) ((u_char *) node + 0x10)`. `CList<CMapPiece>::data`
  sits at 0x10 because `CMapPiece` is quadword aligned.

## Notes

- `node->pGetData()` here produces the same instructions with the piece and
  piece-frame registers exchanged (`s3`/`s4`); the direct field address
  matches. The other walks in the unit keep `pGetData()`.
