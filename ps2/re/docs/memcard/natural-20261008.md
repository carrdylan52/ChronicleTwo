# memcard: natural typed access (2026-10-08)

## Replaced

- `CMemoryCardManager::InitSaveFileInfoTable`: clears `dir_table[entry_no]`
  in a `for` loop instead of reaching each entry through a
  `CMemoryCardManager *` displaced by a byte offset.
- `CMemoryCardManager::Initialize`: the save buffer's placement `new` takes
  the `u_long128 *` from `Alloc` without a same-type cast.

## Kept

- `(char *) path` and `(char *) icon_sys.title_name`: the buffers are
  `unsigned char` because the libmc name parameters are
  `const unsigned char *`; the casts pass them to the C string functions.
- `MakeCheckDigit(0, (char *) &save_buffer->save_data, ...)` and the
  `write_buffer`/`read_buffer` assignments treat save records as raw bytes
  for checksums and card I/O.
