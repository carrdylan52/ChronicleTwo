# menucommon: natural typed access (2026-10-08)

## Replaced

- `_MENU_FORM_VIBECNT`: the second argument slot is a typed
  `SPI_STACK *next_slot = stack + 1`, matching the file's other two-argument
  handlers, instead of a `char *` holding `(char *) (stack + 1)` and a cast back.

## Kept

- `MenuCommonReadData` walks the name list with a byte offset,
  `*(char **) ((u8 *) names + i)` with `i += 4`. Retail keeps the list base and
  a byte offset in separate registers (`addu v0,s4,s1`). Both `names[i]` with
  `i++` in a `while` loop and the same with the locals' declaration order
  swapped produce the same instructions with the offset and `size` registers
  exchanged (`s1`/`s2`). A `for` loop moves the increment after `Align64` and
  reorders the loop tail.
