# Natural visual Copy pair: complete private impact

The atomic Fix/Motion Copy proposal passes complete private wrapper, object,
linker and PAL checks. Removing the unsupported handwritten MDT assignment
declaration lets the ordinary derived assignments emit the genuine generated
MDT member. All game bytes and relocation targets remain exact. This evidence
does not activate the unowned header or count either Copy as a production
promotion; production remains 34 accepted callers across 21 units.

The owning analyses are
[Fix Copy](../mg_visual/placement-new-copy-derived-20261009.md) and
[Motion Copy](../visualmotion/placement-new-copy-derived-20261009.md). Their
frozen natural sources, sole declaration removal and exact two after-inline
rows are unchanged. The generated MDT assignment has retail body 0x98 at
0x1413F0, processor-coalesced binding 13 in native output, and normal WEAK
binding after existing postprocessing. No handwritten generated member,
manual vtable, compiler change or source steering helper is introduced.

## Explicit metadata differences

Each full ELF differs from its actual baseline. The MDT assignment changes
GLOBAL to normal WEAK binding while preserving its address and 0x98 body.
The MDT table's symbol size changes placeholder 0x50 to actual 0x48, with
identical 0x50 storage and targets. Three normal compiler attribute-section
symbol ownership changes accompany removal of the two assembly Copy bodies
and emission of the generated assignment. The linked `.mwcats`, `.comment`
and `.reginfo` payloads remain equal; symbol/string metadata and following
file offsets move. The raw `.relmain` indices change in 98,383 entries;
their named target tuples remain exact. These changes are preserved explicitly.

The two owning object payloads, layouts and named references match the
accepted wrappers. All 40 other MGVisual and 19 other Motion function bodies,
definitions and named references remain exact. Referenced undefined table
symbols acquire their actual OBJECT sizes; this is separately recorded
metadata, not a claim of raw owning-object identity.
