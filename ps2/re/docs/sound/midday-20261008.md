# Sound midday matching evidence (2026-10-08)

## Remaining function

`Init__6CSoundFiiii` is the only guarded sound function at lane base
`c79e57c`. Its existing notes' scheduling and compiler-history exclusions
were read before these trials. `decompile.sh Init__6CSoundFiiii` confirms
the server/context initialization, generic per-port clearing, and special
port configuration described there; the existing MIDI types are retained.

Private copies use MWCC 3.0-011126, canonical `-O3,p` flags, and the
Satan's Fiddle adapter in `chronicletwo_dev:sf-d8bf13c`. The unchanged draft
remains 12/480 differing words, with `0x77C` native bytes in the retail
`0x780` extent. The other 36 functions match in every trial.

## New assignment-grouping trials

| Source hypothesis | Init result |
|---|---:|
| Chain the last two zero kind assignments | 12/480 |
| Chain the last three zero kind assignments | 12/480 |
| Chain all seven zero kind assignments at the last group | 20/480 |
| Move port 11's zero immediately before its direction | 15/480 |
| Move port 11's zero immediately after its direction | 15/480 |
| Move port 11's zero immediately before its SPU-address pair | 32/480 |
| Move port 11's zero immediately after its SPU-address pair | 33/480 |
| Move port 11's zero immediately before its configuration ID | 35/480 |
| Move port 11's zero immediately after its configuration ID | 35/480 |
| Combine port 11's kind/configuration reset in a comma expression | 35/480 |
| Copy the established zero kind from port 0, 3, 7, 9 or 12 | Each grows to `0x784`, beyond retail `0x780` |
| Chain seven zero kinds at the first group, in three natural port orders | Each 24/480 |

Short zero chains preserve the original scheduling. Relocating port 11's
kind reset beside its direction advances another direction byte store into
the unwanted early slot and changes later direction scheduling. Address
and configuration adjacency disturb additional special-port stores.
Copying an already configured port kind retains a load rather than
propagating the known zero, so it grows the function. The full-group chains
change scheduling without closing the original mismatch.

None improves 12/480; no source or header edit is retained. The unresolved
blocker is still the early port-11 kind-zero store at `+0x518` rather than
retail's `+0x548`. These are integer stores, so no float argument selector
is applicable and no Satan's Fiddle row is proposed.

## Final lane validation

The baseline and final game builds both have 147/149 passing units; only
`nd_meswin` and `actscript` fail. The PAL verifier reports the same `0x26`
differing `.text` bytes, first at `0x0015C5AD`, with every other file-backed
section and memory end (`0x01F64A00`) passing. All 149 complete game-object
SHA-256 hashes are identical before and after the lane's wavetable header
change. This unit passes its complete byte and resolved-relocation check.
No function is promoted in this lane; coverage remains 6,686 matched,
169 guarded drafts, 15 assembly-only functions and two fuzzy functions.

Validation receipts are `.private/media-midday/baseline-build.log`,
`baseline-objects.log`, `final-build.log`, `final-objects.log`,
`object-hash-comparison.json` and `final-summary.txt`.
