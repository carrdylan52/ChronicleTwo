## Result

`EditDraw__Fv` retains **8/860** relocated-field-masked differing words,
with a `0xD6C` body in its `0xD70` reservation. No source, header or profile
change is retained and the function stays guarded.

The first texture-list count acquisition differs at `+0x428/+0x42C`: native
copies `v0` to `s3` before testing it; retail tests `v0` first. The forward
list's count acquisition has the same ordering discrepancy at
`+0x6EC/+0x6F0`. Its count and byte induction additionally exchange `s3`
and `s4` at `+0x6FC`, `+0x700`, `+0x724` and `+0x72C`.

## New exclusions

- Retail-local `MainScene`, `LoopMode`, `EditDrawFlag`,
  `EditDrawCancelFlag` and `WalkChara` are tested as static definitions in
  private source copies. Each leaves the eight-word result unchanged.
  The retail `MainScene` pointer at `0x37D328` corresponds to this unit's
  disambiguated `MainScene__2`, rather than the earlier large scene object.
- Unsigned reverse count, shared count and map index, with signed API-bound
  comparisons preserved, give 179, 197 and 196 words respectively.
  An unsigned texture-group index gives nine words. These tests change no
  field width or dependency header.
- Moving the declarations of the four actual count/index variables to the
  beginning or end of the existing declaration group gives 8–32 words.
  Explicit signed casts on either acquired count leave eight words.
- Expressing either loop limit as `index <= count - 1` exceeds the retail
  reservation: reverse only `0xD74`, forward only `0xD7C`, both `0xD84`.

The full wrapper/fixup probe has exactly one canonical problem, in
`EditDraw` at `0x001AFC28`; it checks `0x6D98` bytes and 2,128 relocations.
No relocation-resolution problem accompanies that register/order residual.
