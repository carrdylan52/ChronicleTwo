# mg_dataset: natural typed access (2026-10-08)

## Replaced

- `conv_new_text`: the source name is read as `*src` and `src[1]` instead
  of through `(s8 *)` views of the `char *` parameter.
- `htoi`: the length scan walks `char *end = text`.
- `mgSetFrameAttr`: the frame name scan reads `*text` and `text[1]` directly.

## Kept

- `htoi`: `((u8 *) (back + (s32) text))[-1]` reads digits from the end.
  Retail adds the text address to the position (`addu v1,v1,a0`); both
  `(text + back)[-1]` and `(back + text)[-1]` put the pointer first.
- MDS and MDT sections are located from serialized byte offsets
  (`object_ofs`, `mdt_ofs`, `vertex_ofs`, `object->size`), and the writers
  measure sizes as byte differences from the header.
- `(int) mds % 16` tests the file buffer's alignment.
