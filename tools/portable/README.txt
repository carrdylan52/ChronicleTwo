ChronicleTwo Windows portable playtest

1. Extract this entire ZIP into a writable folder.
2. Open Play.exe.
3. Choose your PAL European Dark Chronicle ISO (SCES-51190).
   You can also paste its full path into the setup window.
4. Choose Prepare and play. The game opens when extraction finishes.

An ISO beside Play.exe is offered automatically if it is the only matching disc.
Keep your own disc image; no game assets are included in this download.

Later launches reuse the prepared game files. Settings, saves, extracted files
and logs stay in the userdata folder beside Play.exe. You can move the entire
folder, including userdata, while the game is closed.

To update: close the game, then replace the program files with the new package.
Keep userdata. If a new build needs fresh game files, it asks for your ISO again;
existing saves and settings are retained. Keep a backup of userdata before
trying a different build.

This is an early native-port playtest. A complete campaign and all sub-games
are not qualified. A compatible graphics driver is required.

If setup fails, use Open logs. Game errors are recorded in userdata/logs/game.log.
The previous run is retained as game.previous.log (and setup.previous.log).
When reporting a problem, include build-info.json, the relevant log, your
graphics card/driver, and the action that triggered it. Do not upload your ISO
or extracted game files.
