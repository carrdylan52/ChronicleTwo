## Retained checkpoint and hygiene boundary

The existing draft remains **7/260** words and `0x410` bytes. Its only
raw-word differences are the pointer spills/reloads at `+0x2C`, `+0x34`,
`+0x44`, `+0xFC`, `+0x1E8`, `+0x374` and `+0x380`.
The full wrapper/fixup probe checks `0x5440` bytes and 877 relocations and
has one byte problem at `0x0029132C`.

This score does not make the draft eligible for promotion. It contains
ActiveDngMap/Ident wrappers, scalar alignment attributes, a placed-parts
pointer walk and a grid-cell pointer walk. The natural trials remove both
wrappers and all scalar attributes and index the established CMapParts
and CAutoMapParts arrays instead. No lower-scoring non-natural form is
introduced or retained.

## New natural-source exclusions

- The direct-call, fully indexed base gives 219/264 words and a `0x420`
  body, exceeding retail's `0x410`. Declaring the actual polygon, hit,
  attempt, axis and part-query locals at use retains that result; moving
  the retry-count initialization gives 222.
- Separating placement and collision receivers with both walks indexed
  gives 227 words for a pointer or 234 for a reference, with `0x420` bodies.
  These are distinct from the earlier 33-word receiver trial, which still
  used pointer induction.
- Caching the grid array before indexed traversal gives 237/266 words
  and `0x428` bytes. A cell reference has the same result; direct cell
  indexing gives 236/268 and `0x430`. Separating the occupied count gives
  237/262 and `0x418`. Separating the placement-capacity output gives 236.
- Keeping a typed const placement-array base while indexing yields the
  best new natural bound, **212/264**, with a `0x420` body. A const pointee
  has the same result. The double-negated sentinel test enlarges these
  forms to `0x428`; it does not reproduce the retail walk.
- An AUTOMAP_ATTR local retains 219/264. A u16 attribute local gives
  222/266 and `0x428`; the established CAutoMapParts field remains s16.
  Const parameters, SDK vector aliases and unsigned grid indexing do not
  recover the pointer slots or array traversal.
- Scoped optimization level 4 or global optimization on retains the
  fully indexed base result. Level 2 emits `0x4DC`; global optimization
  off retains `0x420` with 240/264 words. No pragma is retained.

The fresh symbol check confirms DngMainScene is GLOBAL, so it is not
localized. No dependency/header correction or compiler selector is proposed.
The remaining boundary is a natural representation of the two array walks
