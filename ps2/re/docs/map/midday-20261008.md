## AddPartsGroup

`AddPartsGroup__4CMapFPcP9CMapPartsP9mgCMemory`, retail address `0x15DA50`,
looks up or creates a named parts group, placement-constructs a list node,
attaches the requested part and appends the node to the group.
The current native body is `0x104` bytes against a `0x100` retail extent;
the instruction comparison counts 19 differences over the 65-word native
body, including its extra word. The canonical draft checker separately
reports the size overrun rather than accepting a score.

m2c and the retail construction window confirm that the carried
`PartsGroupData::parts` is cleared once during construction, before virtual
list initialization. The caller draft clears it again under an explicit
post-construction null test. Removing that caller clear has already been
measured in `notes.md`; its worse 26/64 result is not retried or retained.
The construction guard also copies the allocation result before testing its
saved register, while retail tests `v0` and copies it in the delay slot.

`PartsGroupData` is one pointer, not an evidenced homogeneous array. The
constructor-classification findings in `../funcpoint/placement-new.md` do
not authorize adding a loop, an extra helper or a different member layout
solely to change the guard. A natural statement-shaped constructor preserving
all retail operations remains the reconsideration condition.

## CreateDrawRect

`CreateDrawRect__4CMapFP9mgCMemoryP9mgVu0FBOXP9mgVu0FBOXi`, retail address
`0x15E210`, reserves a visibility rectangle and lists the placed parts whose
bounds intersect its selection box. The current native body has 50/112
positional word differences. Its `CList<CMapParts *>` construction has the
same allocation-result scheduling boundary described above.

The body calls `CMapParts::GetBoundBox`, `mgClipInBox` and the existing native
box assignment; its retail instruction listing contains no VU0 instructions.
This target is parked for list construction, not for a VU0 implementation.
The pointer payload has no constructor array to initialize. No assembly,
shared header, compiler profile or game source is changed in this unit.
