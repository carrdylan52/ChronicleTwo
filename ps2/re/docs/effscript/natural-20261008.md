# effscript natural access (2026-10-08 night)

Byte-identical object (`check_objects effscript`: 0xEA7C bytes, 1285 relocations).

## Replaced
- The unit's static `GetStackInt`, `GetStackFloat`, `GetStackString` and `SetStack` overloads use
  `RS_STACKDATA::val.f` / `val.s` instead of `*(float *) &val.i` and `reinterpret_cast`, and the
  `RS_INT` / `RS_FLOAT` / `RS_PTR` type names.

## Kept
- `_SPT_VAN_SET_POS`, `_SPT_ADD_POS`, `_SPT_SET_VELO_POS`, `_SPT_SET_ACC_POS`:
  `stack = (RS_STACKDATA *) ((u8 *) stack + n * sizeof(*stack))`. `stack += n` lets MWCC fold the
  advance into the next use instead of updating the pointer register where retail does.
