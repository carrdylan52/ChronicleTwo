# menudraw: natural typed access (2026-10-08)

## Replaced

- `CMenuPosDataForm::Initialize`: every byte-offset store through
  `u8 *bytes = (u8 *) this` is a named field: `next_x`/`next_y` (0x24/0x28),
  `mtype = MENUFORM_MTYPE_N` (0x20), `rgba_bit` (0x50), the `rgba_add`,
  `rgba` and `rgba_target` channel arrays (0x51/0x55/0x59), `counter` (0x18),
  `chara` (0x38), `chara_tex_block`/`unk_36` (0x34/0x36),
  `action_no`/`action_state` (0x5E/0x60) and `sub_no` (0x1C).
- `MenuPosDataTypeInit`: `part->tex = NULL` instead of `*(int *) &part->tex = 0`.
- `CMenuPosDataForm::SetRGBACalcParam`: `rgba_add[index]` and
  `rgba_target[index]`.
- `CMenuPosDataForm::GetEnableEnterPart`: `for` loop over `parts[i]`.
- `CMenuPosDataForm::MenuFormStep`: the colour fade loop indexes `rgba_add`,
  `rgba` and `rgba_target`; the step is read once into an `s8 step`.
- `CheckItemBoardFunc_MenuIconDrawPrepare` and
  `MenuItemBrdItemIconEffectMalloc`: `for` loops over `parts[i]`.
- `CRepairManager::LoadDataBG`: `(unsigned int *) &memory->stack[memory->stack_used]`.
- `InitInitBuildUpInfoEffectPos` and `DrawBuildUpInfoEffect`:
  `MenuVerticalLine[i]`.

## Kept

- `CRepairManager::SetStack`: `*(int *) &memory->stack` for `base` and the
  mode-1 `top`. Reading the pointer as a value (`(int) memory->stack`) changes
  the order of the `subu`/`sll`/`addu` that form the stack end.
- `CRepairManager::Generate`: `(u8 *) (slot * 0x30) + (int) this` then
  `+ 0x24`. `&effect_stack[slot]` matches except for the operand order of
  the `addu` (retail adds `this` to the scaled slot).
- `CLevelUpEffect::Step`: byte `offset` walk over `l_levelup_pos` and
  `l_levelup_vec`. `l_levelup_pos[i]` element pointers rotate the offset,
  counter and generate-counter registers; indexing at every use changes the
  instruction count.
- `CMenuPosDataManage::MallocPallet` and `SearchTransPalletNo`: `(u8 *)` views
  of the `u_long128` CLUT buffers read and write raw RGBA texel bytes.
