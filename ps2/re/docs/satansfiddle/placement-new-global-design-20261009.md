# Global-after design and identity obligations

The current34 historical hybrid preserves all149 wrapped objects and the
entire accepted34 ELF; its paired native diagnostic preserves all6,779
scoped zeros and adds two inadmissible guarded zeros. Those results justify
investigating a semantic profile-level default. They do not implement or
validate a strict global engine. This note records a frozen design and its
subsequent critique, including a correction to overly broad name obligations.

## Initial inactive schema

The first design proposes `placement_new.global_after_constructor_inline`
with an exact allocator allowlist, the sole existing NewTex before-inline
row in `statement_conversions`, and `match_assertions` for the other33 known
accepted identities. Those33 assertions retain43 positive expected sites;
NewTex retains one. Assertions audit counts and never determine admission
or timing. This preserves the44 existing obligations while reducing timing
selectors to one; it makes no claim about the total number of additional
globally eligible roots.

The game profile's witnessed allocator is `__nw__FUiP1`; existing genuine
fixtures use `__nw__FUiPv`. The allowlist explicitly names supported ABIs.
Raw `__nw` spelling or two actual arguments cannot establish an overload.
The default applies to actual scalar roots with original constructor inline
class6. Class0/3, arrays, ordinary same-type calls and non-root constructor
calls remain outside this operation.

The optional fields, parser/adapter changes and engine state refactoring are
unimplemented at the design freeze. The current parser rejects the fields.
Global installation/activation must become independent of whether scoped
rows exist. `Record.row` currently supplies both timing and witness/count
ownership; a global record needs those responsibilities separated. The
adapter must retain global settings through both wrapper passes and native
invocation, while filtering exact assertions by real logical unit.

The historical hybrid's exception is unit-wide before-template mode in
mg_tanime, not a tested exact before override plus strict global fallback.
Its56 selected events per pass correspond to44 accepted sites plus12 extra
diagnostics. Three further first-pass callbacks have raw `__ct`, raw `__nw`,
class6 and selected=false, in convviewlp, dng_main and memcard. Their exact
allocator ABIs and complete strict eligibility are unknown from those saved
traces. No game source or reserved source/header was inspected to expand them.

## Corrected division of identity requirements

The first design required exact mangled caller/constructor names for every
global root and exact allocator ABI before the conversion action. Those
were conservative design choices rather than requirements in the pntc
brief. Its global-capability branch is distinct from the exact per-site
fallback. The later critique supersedes those universal name obligations
without changing the frozen original design.

NEW_ENTER already verifies the actual kind-0x3a scalar root, captured direct
allocator/constructor call nodes and canonical live objects, then reads
the constructor's original inline-info class. INLINE_READ must agree with
the exact captured constructor object and call node, EBP/EDI metadata and
class6 in both memory and EAX. These checks establish root ownership without
comparing textual names. The live caller object and epoch/caller/root key
remain necessary even when no caller spelling is required. The canonical
resolver's function-alias kind6 is distinct from constructor inline class6.

| Obligation | Necessary identity evidence |
| --- | --- |
| Unasserted global semantic root | Captured canonical live objects, exact root call and original class6; no universal mangled caller/ctor name |
| Supported allocator ABI | Normal exact allowed allocator identity before publication; unsupported or unresolved admission rejects |
| NewTex before exception | Unambiguous exact/provisional unit/caller/allocator/ctor association at the before action, with final ordinary witnesses |
| Count assertions | Exact association for every possible match, including excess or unwitnessed candidates; counts cannot steer conversion |
| Optional diagnostics | Already available raw/exact names, clearly labelled; no fabricated special-member identity |

An absent ctor name cannot by itself establish that a root is unasserted.
Units with no exception/assertion rows exclude those associations directly.
Elsewhere possible matches must resolve or reject, even after an assertion's
expected total is reached. All three saved raw-ctor units have zero current34
placement rows, so their caller/ctor spellings are unnecessary for the known
NewTex exception or33 assertions. Their allocator and structural safety
obligations remain unproven.

Production's genuine implicit-constructor regression selects exact Shadow/
FixedShadow identities and correctly rejects an unwitnessed generated ctor.
That result does not require a selector-free global operation to invent or
obtain the same spelling. Current scoped behavior and that regression's
expectation remain valid.

## Admission timing, safety and remaining evidence

The measured name reader can obtain an already populated object+0x30 link
cache before conversion. Otherwise object+8 supplies only a raw identifier;
the ordinary mangler-return observer is the demonstrated route to an exact
overload. Its availability for the three raw callbacks is unknown. Current
function-type decoding only proves a void-return slot for retained empty
returns; it does not decode allocator parameter types or overload ABI.
No new undocumented field layout is justified by argument count.

The global allowlist itself supplies expected allocator identities. Existing
bounded raw-stem provisional nomination and late exact transactional
verification may therefore be reusable without caller/ctor selector rows.
This needs genuine evidence: speculative conversion must never publish an
excluded or unresolved overload, and may otherwise reject an ordinary
excluded allocation that could not be ruled out early. Early exact ABI was
a conservative choice, not a proven mandatory action-point invariant.

All structural safety checks remain necessary: exact root INLINE_READ,
single owned construction per verified statement, bounded expression and
retained-body walks, hidden/deferred/cleanup rejection, exactly one ordinary
conversion visit, complete records before arena reset, epoch deduplication
and transactional object publication. Wider global activation also requires
measured observer/lifecycle coverage. Removing an unnecessary spelling
condition does not relax ownership, graphs, counts or failure checks.

New implementation evidence must cover selector-free implicit roots,
potential asserted/override roots whose names arrive late or never, same-stem
allocator overloads, mixed global-after/exact-before timing, assertion-only
output independence, bad/excess counts and global publication/arena failure.
The13 production genuine regressions remain a scoped compatibility boundary;
new global behavior needs its own tests and actual corpus/link acceptance.
The pn17 raw-filter experiment remains a separate broad diagnostic.
