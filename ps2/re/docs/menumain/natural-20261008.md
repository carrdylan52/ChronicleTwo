# menumain natural access (2026-10-08 night)

## Replaced
- `MakeMenuTopic`: the topic width is measured with
  `TopicFont.CalcDrawWH(TopicFont.str, ...)` instead of passing the font object's address as
  `char *` and casting it back to `CFont *`; `str` is `CFont`'s first member.
- `MenuInternInit`: the message window's placement `new` takes the
  `u_long128 *` from `Alloc` without a same-type cast.

## Kept
- `CursorSaveOptionState`: `(u8) !*(int *) &save_data->config`. Retail forms the full address of
  `config` (`lui`/`ori`/`addu`) and loads at offset 0; `save_data->config.cursor_save`, a
  `SV_CONFIG_OPTION *` local and `save_data->GetConfig()->cursor_save` all fold the offset into
  the load (`lui 0x2` + `lw -14988`) and shorten the function by one word.
