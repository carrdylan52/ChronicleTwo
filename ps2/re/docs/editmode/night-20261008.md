first query's count, ground count and map offset all match retail.
Simulating a move of the corner's virtual number alone never keeps it;
removing a single edge to any of eight retained loop/call-crossing values
can keep it. These simulations only inspect captured graphs; they do not
modify compiler allocation or emitted code.
