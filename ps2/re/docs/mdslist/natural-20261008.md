# mdslist: natural typed access (2026-10-08)

## Replaced

- `CMapPiece::Initialize`: the material clear is
  `memset(&material[i], 0, sizeof(PieceMaterial))` without a byte offset.
- `CIMGList::LoadIMGFile`: the `slot` alias is set from `this` without a
  same-type `(CIMGList *)` cast.
- `CCharacter2` entry: the `(mgCFrame *)` on `CObjectFrame::frame` was a same-type cast.
- `pcpMDS_END`: `mgLoadMDSFile` already returns `mgCFrame *`.
- `CMdsList::GetListID`: `*name == 0` on the `char *` name instead of `*(signed char *) name`.

## Kept

- `(char *) memory->Alloc(...)` for name copies converts a fresh stack
  allocation to the string it holds.
- `CCharacter2` entry: `((CObjectFrame *) chara)->frame` stays; `CCharacter2::frame` (the
  motion frame, `float`) hides the inherited `mgCFrame *frame`.
- `CMapPiece::GetPoly`: `(CColFrame *) frame` is a downcast of the piece's `mgCFrame *`.
